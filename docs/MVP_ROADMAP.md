# RosterOps MVP Roadmap

Phase 0 — Wedge concierge: manually run Send one messy deal with a manager; define canonical brief, campaign, approval, invoice, and reporting schemas; collect gold threads/PDFs; validate 5–20 creator workflow.

Phase 1 — Inbound-to-campaign engine: Resend/Postmark plus Gmail/Outlook adapters, PDF/thread normalization, structured Deal Agent extraction, rate-card matching, redline detection, durable jobs, audit trail, and human approval inbox.

Phase 2 — Manager Workspace: campaign workspace, deliverables/deadlines, creator kickoff, brand drafts, approval tracking, invoice timelines, reporting checklist, Inbox/Comms and Campaign agents, manager voice and memory.

Phase 3 — Manager beta: Finance and Logistics agents, payment tracking, calendar/travel, creator preferences, observability, corrections, deletion, accessibility, and pilot launch.

Phase 4 — Agency Command Center: authorized all-manager roster, pipeline, revenue, workload, agent health, cross-agency memory, leadership workflows, and aggregate forecasting.

Phase 5 — Brand/Creator network layer: Sales/Outreach enrichment, decision-maker intelligence, Creator and Career/Strategy agents, proactive pitching, Brand/Castlane representation layer, and ecosystem permissions.
